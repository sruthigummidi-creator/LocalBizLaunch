# LocalBiz Launch — Website UI Preview

This ZIP contains the responsive front-end starter for the LocalBiz Launch student project.

## Included
- `index.html` — common public landing page for customers and business owners
- `login.html` — shared login UI
- `register.html` — customer/business-owner registration UI
- `style.css` — landing page styling and green/cream/gold theme
- `auth.css` — authentication page styling
- `script.js` — responsive menu and sample listing/category search
- `auth.js` — client-side form checks only

## Open the website
1. Extract the ZIP.
2. Open `index.html` in Chrome or Edge.

For the best development workflow, open the extracted folder in Eclipse or VS Code. The pages can also be served with a local static server.

## Important project status
This is a **front-end UI preview**, not a completed full-stack application. The business cards are sample data. Login and registration do not create accounts, and no MySQL database is connected yet. The planned backend is Java Servlets + JDBC + MySQL on Apache Tomcat. Password hashing, role authorization, business verification, database queries, and real business listing pages must be implemented on the server before real use.

The page uses Google Fonts when an internet connection is available; system fallback fonts are included.
